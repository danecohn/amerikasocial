AMERIKA OS · 3.0 · EARLY ACCESS

Your computer.
Operated by AI.
Run by you.

Amerika OS is its own desktop: a retro-futurist shell with Claude and ChatGPT at the centre. They can open apps, arrange windows, change settings and more through a system-control layer with permissions, approvals, a live activity indicator and a stop switch.

Terminal — quick install
sudo apt install amerika-desktop

After adding the repository below. Then pick Amerika OS on the login screen.

Install

Ubuntu 26.10 for ARM64, using ordinary APT with a dedicated signing key. No trusted=yes, no unauthenticated packages.

  1. Add the signing key

    bash
    sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://www.amerika.social/apt/amerika-archive-keyring.gpg | sudo tee /usr/share/keyrings/amerika-archive-keyring.gpg >/dev/null
gpg --show-keys --with-fingerprint /usr/share/keyrings/amerika-archive-keyring.gpg

    Compare the fingerprint with 9F52 BD98 A8EE 9096 B1BE 7AAC 1063 BBC9 89A1 1133. The same fingerprint is published in the source repository.

  2. Add the repository

    bash
    sudo tee /etc/apt/sources.list.d/amerika.sources >/dev/null <<'EOF'
Types: deb
URIs: https://www.amerika.social/apt
Suites: stable
Components: main
Architectures: arm64
Signed-By: /usr/share/keyrings/amerika-archive-keyring.gpg
EOF

sudo tee /etc/apt/apt.conf.d/50amerika-social >/dev/null <<'EOF'
Acquire::http::www.amerika.social::Pipeline-Depth "0";
Acquire::https::www.amerika.social::Pipeline-Depth "0";
EOF

    The second file turns off HTTP pipelining for this host only: the proxy in front of Amerika Social rejects pipelined requests, which makes large installs fail intermittently. The amerika-repo-keyring package keeps both files up to date.

  3. Install the desktop

    bash
    sudo apt update
sudo apt install amerika-desktop

    Log out and choose Amerika OS from the session menu on the login screen. Your login manager and your other sessions stay exactly as they are, so you can always switch back. Coming from Amerika OS 2.x (the COSMIC version)? After the upgrade, sudo apt autoremove clears the COSMIC packages you no longer need.

AI at the centre

Claude and ChatGPT are the first two things in the top bar and the dock. In Settings › AI & Assistants you press Connect for each app once; from then on they can use the Amerika system tools. Nothing is connected until you do that.

What they can do

Open and close apps, focus, tile, move and resize windows, switch desktops, set volume, brightness, display scale, Wi-Fi and power profile, send notifications, read and write files in your home folder, and (with your approval) run shell commands.

You decide how much

Ask every time, Balanced (everyday changes run, risky ones ask) or Trusted. Shutting down, restarting and deleting always ask. Each app can be switched off separately.

You always see it

The top bar shows which app is operating the computer. Ctrl+Alt+Esc or the Stop button pauses everything at once, and every action is recorded in an activity log you can read in Settings.

An open door

The tools are a standard MCP server (amerika-mcp), so any MCP-capable assistant can be connected, not just these two.

The desktop

Amerika Shell

Our own top bar, floating dock, launcher, notifications and quick controls, in Python and GTK 4. No Plasma, no GNOME Shell.

Amerika Settings

Our own settings app: AI, appearance, display, sound, network and power.

Retro-future, all the way

Neon cartridge app icons, chrome glass panels, three horizon wallpapers, and accent colours you can change.

Your apps

Social, Venture (Firefox-based), Office, Files, Terminal, Text, and the Amerika Software manager.

Supported systems

ReleaseUbuntu 26.10 (stonking)
ArchitectureARM64 (aarch64) only for this release. x86-64 packages are not built or tested yet, so they are not offered.
Under the hoodThe KWin compositor (from KDE) handles windows and effects. The shell, settings and AI layer are Amerika's own. Screen locking is KDE's stock locker for now, and authentication prompts use KDE's polkit agent.
AI appsClaude and ChatGPT are separate apps you install yourself; Amerika OS does not bundle them. The stand-in icons for them are generic, not their logos.
Updatessudo apt update && sudo apt upgrade, or Amerika Software. Removal: sudo apt remove amerika-desktop.

Source, licenses and honesty

  • Everything is built from public sources: shell, settings, AI layer and packaging, Social, Venture, Office.
  • Amerika OS is a desktop environment, not a new Linux distribution or kernel, and it uses KWin as its window compositor.
  • Files, Terminal and Text are Amerika-branded launchers for GNOME Files (Nautilus), Ptyxis and GNOME Text Editor, which stay installed under their own licenses.
  • Venture is Mozilla Firefox 158.0.1 with Amerika branding (MPL-2.0), not a full rebuild of Gecko. Office is an Electron wrapper for the hosted portal and keeps ONLYOFFICE Community Edition branding and notices.
  • An AI app that can operate your computer can make mistakes or be misled by what it reads. That is why risky actions ask first, and why the stop switch and the activity log exist. Connect only apps you trust.
  • Early access: the shell and the AI layer are tested in an isolated KWin session (windows, approvals, permissions, the stop switch) and with automated tests, but not yet through a real login on many machines. Report problems from the support page.
