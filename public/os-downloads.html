AMERIKA OS · 1.0 · EARLY ACCESS

The Amerika desktop.
One command away.

A top menu bar, a floating dock that never hides, and a signed package repository hosted right here on Amerika Social. Social, AI, browsing, files and terminal, built on the COSMIC desktop.

Terminal — quick install
sudo apt install amerika-desktop

After adding the repository below. Then pick Amerika OS on the login screen.

Install

Ubuntu 26.10 for ARM64, using ordinary APT with a dedicated signing key. No trusted=yes, no unauthenticated packages. The COSMIC desktop itself is installed from this same repository.

  1. Add the signing key

    bash
    sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://www.amerika.social/apt/amerika-archive-keyring.gpg | sudo tee /usr/share/keyrings/amerika-archive-keyring.gpg >/dev/null
gpg --show-keys --with-fingerprint /usr/share/keyrings/amerika-archive-keyring.gpg

    Compare the fingerprint with 9F52 BD98 A8EE 9096 B1BE 7AAC 1063 BBC9 89A1 1133. The same fingerprint is published in the source repository.

  2. Add the repository

    bash
    sudo tee /etc/apt/sources.list.d/amerika.sources >/dev/null <<'EOF'
Types: deb
URIs: https://www.amerika.social/apt
Suites: stable
Components: main
Architectures: arm64
Signed-By: /usr/share/keyrings/amerika-archive-keyring.gpg
EOF

  3. Install the desktop

    bash
    sudo apt update
sudo apt install amerika-desktop

    Log out and choose Amerika OS from the session menu on the login screen. Your current login manager stays the default, and your existing sessions (Plasma, GNOME) are left untouched, so you can always switch back. Install only the pieces you want with apt install amerika-software, amerika-venture, amerika-office or amerika-social. Want the old KDE Plasma variant of Amerika OS? apt install amerika-plasma.

What you get

Amerika shell

Top menu bar with launcher, workspaces, tray and clock. A floating dock for Social, AI, Venture, Files, Terminal, Office and Software. Both stay visible.

Amerika apps

Social, Venture (Firefox-based), Office, AI shortcut, Files, Terminal, Text and Settings, all with Amerika branding.

Amerika Software

A graphical package manager for this repository: install, update and remove with the normal administrator prompt.

Retro-future look

A dark COSMIC theme with crimson accents, a horizon wallpaper and the AmerikaOS icon set.

Supported systems

ReleaseUbuntu 26.10 (stonking)
ArchitectureARM64 (aarch64) only for this release. x86-64 packages are not built or tested yet, so they are not offered.
Desktop baseCOSMIC 1.10 (cosmic-comp, cosmic-panel, cosmic-settings and friends) on Wayland, from System76’s Pop!_OS builds for Ubuntu 26.04. They are re-hosted here unmodified, and their dependencies resolve on Ubuntu 26.10.
Updatessudo apt update && sudo apt upgrade, or Amerika Software. Removal: sudo apt remove amerika-desktop.

Source, licenses and honesty

  • Everything is built from public sources: desktop, packaging and repository tooling, Social, Venture, Office.
  • Amerika OS is a desktop environment built on COSMIC, not a new Linux distribution or kernel. It adds an Amerika session, top bar and dock layout, theme, apps and the Amerika Software manager. COSMIC is System76’s desktop; the 34 COSMIC packages here are their unmodified builds, checked against the signature on their repository and re-hosted by Amerika because Ubuntu 26.10’s APT rejects that repository’s SHA-1-bound key. Package versions end in the upstream commit, e.g. the COSMIC source projects at the tagged commits. COSMIC updates reach you when Amerika re-mirrors them.
  • Files, Terminal, Text and Settings are Amerika-branded launchers for COSMIC Files, Terminal, Edit and Settings, which stay installed under their own licenses (GPL-3.0).
  • Venture is Mozilla Firefox 158.0.1 with Amerika branding (MPL-2.0), not a full rebuild of Gecko. Office is an Electron wrapper for the hosted portal and keeps ONLYOFFICE Community Edition branding and notices.
  • Amerika AI is a shortcut to a web assistant (configurable in /etc/amerika/ai-url); no AI model is bundled.
  • Early access: the Amerika session layout was tested in a nested COSMIC compositor and package-by-package, not yet across a wide range of machines. Report problems from the support page.
