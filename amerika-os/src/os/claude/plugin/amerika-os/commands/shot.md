---
description: "Take a screenshot of the screen or the active window"
argument-hint: "screen | window"
---

Argument: $ARGUMENTS (default window; use screen only if needed). The screen may show private data: say what you are about to capture, then `amerika.screenshot.take {target}`. You get a file path and size, not pixels; report them and that the file is in Amerika's private folder. Do not forward it anywhere.

Rules: follow the privacy-and-safety skill. Verify the result with a read tool and report only what you verified. If a tool fails or the user declines, say so and stop; do not retry or look for another way around the refusal.
