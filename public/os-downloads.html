AMERIKA OS · 1.0 · EARLY ACCESS

The Amerika desktop.
One command away.

A top menu bar, a floating dock that never hides, and a signed package repository hosted right here on Amerika Social. Social, AI, browsing, files and terminal, built on KDE Plasma.

Terminal — quick install
sudo apt install amerika-desktop

After adding the repository below. Then pick Amerika OS on the login screen.

Install

Ubuntu 26.10 ("Stonking Stingray") for ARM64 with KDE Plasma 6.7, using ordinary APT with a dedicated signing key. No trusted=yes, no unauthenticated packages.

  1. Add the signing key

    bash
    sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://www.amerika.social/apt/amerika-archive-keyring.gpg | sudo tee /usr/share/keyrings/amerika-archive-keyring.gpg >/dev/null
gpg --show-keys --with-fingerprint /usr/share/keyrings/amerika-archive-keyring.gpg

    Compare the fingerprint with 9F52 BD98 A8EE 9096 B1BE 7AAC 1063 BBC9 89A1 1133. The same fingerprint is published in the source repository.

  2. Add the repository

    bash
    sudo tee /etc/apt/sources.list.d/amerika.sources >/dev/null <<'EOF'
Types: deb
URIs: https://www.amerika.social/apt
Suites: stable
Components: main
Architectures: arm64
Signed-By: /usr/share/keyrings/amerika-archive-keyring.gpg
EOF

  3. Install the desktop

    bash
    sudo apt update
sudo apt install amerika-desktop

    Log out and choose Amerika OS from the session menu on the login screen. Your existing Plasma session is left untouched, so you can always switch back. Install only the pieces you want with apt install amerika-software, amerika-venture, amerika-office or amerika-social.

What you get

Amerika shell

Top menu bar with the Amerika menu, global menu, tray and clock. A floating dock for Social, AI, Venture, Files, Terminal and Software. Both stay visible.

Amerika apps

Social, Venture (Firefox-based), Office, AI shortcut, Files, Terminal, Text and Settings, all with Amerika branding.

Amerika Software

A graphical package manager for this repository: install, update and remove with the normal administrator prompt.

Retro-future look

Dark glass, chrome and crimson neon, a horizon wallpaper and the AmerikaOS icon set.

Supported systems

ReleaseUbuntu 26.10 (stonking)
ArchitectureARM64 (aarch64) only for this release. x86-64 packages are not built or tested yet, so they are not offered.
Desktop baseKDE Plasma 6.7 and KWin on Wayland. Packages depend on the matching Plasma 6.7 packages and install them automatically.
Updatessudo apt update && sudo apt upgrade, or Amerika Software. Removal: sudo apt remove amerika-desktop.

Source, licenses and honesty

  • Everything is built from public sources: desktop, packaging and repository tooling, Social, Venture, Office.
  • Amerika OS is a desktop environment built on KDE Plasma and KWin, not a new Linux distribution or kernel. The shell links to the stock Plasma views so it receives upstream fixes.
  • Files, Terminal, Text and Settings are Amerika-branded launchers for KDE Dolphin, Konsole, Kate and System Settings, which stay installed under their own licenses.
  • Venture is Mozilla Firefox 158.0.1 with Amerika branding (MPL-2.0), not a full rebuild of Gecko. Office is an Electron wrapper for the hosted portal and keeps ONLYOFFICE Community Edition branding and notices.
  • Amerika AI is a shortcut to a web assistant (configurable in /etc/amerika/ai-url); no AI model is bundled.
  • Early access: the Amerika session has been tested in an isolated nested compositor and package-by-package, not yet across a wide range of machines. Report problems from the support page.
