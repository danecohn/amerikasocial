---
description: "Shut the computer down (always confirm)"
---

Confirm first: all apps close and the computer powers off; you cannot turn it on again. Ask whether work is saved. After a clear yes call `amerika.power.poweroff` (critical; the shell asks again).

Rules: follow the privacy-and-safety skill. Verify the result with a read tool and report only what you verified. If a tool fails or the user declines, say so and stop; do not retry or look for another way around the refusal.
